# 使用指南

net-tutor 是一个纯前端的二层网络教学工具，包含交互式课程、练习题和故障排查三个模块。

## 快速开始

### 1. 启动本地服务器

由于使用了 ES6 模块，需要通过 HTTP 协议访问（直接双击 HTML 会被 CORS 阻止）：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server -p 8000
```

然后在浏览器打开：
- 交互式课程：http://localhost:8000/index.html
- 练习题系统：http://localhost:8000/quiz.html
- 故障排查：http://localhost:8000/troubleshoot.html

### 2. 选择学习路径

**从零开始**：
1. 先看 `index.html` 的阶段 0-3 课程，理解 FDB、VLAN、STP 的工作原理
2. 然后做 `quiz.html` 的 30 道题，巩固知识点
3. 最后挑战 `troubleshoot.html` 的 4 个故障场景

**已有基础**：
直接进入 `troubleshoot.html`，看能否诊断出 4 个场景的根因。

## 交互式课程（index.html）

### 阶段切换

默认加载阶段 0，切换到其他阶段：

1. 打开 `index.html`
2. 找到第 10 行：`import { spec, injections } from './src/lessons/stage0.js';`
3. 改成 `stage1.js`、`stage2.js` 或 `stage3.js`
4. 刷新页面

### 键盘操作

| 键 | 作用 |
|---|---|
| <kbd>→</kbd> 或 <kbd>Space</kbd> | 下一步 |
| <kbd>←</kbd> | 上一步（从头重放到当前步） |
| <kbd>Home</kbd> | 回到初始状态 |
| <kbd>End</kbd> | 快进到最后一步 |

### 界面说明

- **左侧拓扑图**：显示节点、链路和当前帧的位置
  - 蓝色高亮：当前帧所在的节点/链路
  - 绿色箭头：帧的流向
  - 端口标签：显示端口名称（如 p1、p2）

- **右上 FDB 表**：显示每个交换机学到的 MAC 地址
  - 列：MAC 地址、端口、VLAN（阶段 2 起）、学习时间
  - 新增条目会高亮显示

- **右下事件日志**：显示每一步的操作
  - 蓝色：当前事件
  - 灰色：已完成的事件
  - 点击可跳转到该步

## 练习题系统（quiz.html）

### 功能介绍

- **30 道题目**：覆盖 FDB、VLAN、STP 三个阶段
- **5 种题型**：单选、多选、填空、判断、场景题
- **即时反馈**：提交后立即显示正确答案和解析
- **错题本**：自动记录答错的题目，答对后移除
- **进度统计**：显示总题数、已作答、正确数、错题数

### 使用流程

1. 选择阶段：点击顶部的"阶段 1/2/3"按钮
2. 作答：选择或填入答案
3. 提交：点击"提交答案"按钮
4. 查看解析：答案下方会显示详细解释
5. 查看课程：点击"查看课程"按钮跳转到相关课程（如果有）

### 错题本使用

1. 点击顶部的"错题本"按钮
2. 查看所有答错的题目
3. 点击"重做"按钮重新作答

### 数据持久化

- 错题和进度保存在浏览器的 localStorage
- 刷新页面不会丢失数据
- 清除浏览器数据会重置进度

## 故障排查演练（troubleshoot.html）

### 4 个场景

1. **VLAN 配置错误**
   - 现象：h1 (VLAN 10) 无法 ping 通 h3 (VLAN 10)
   - 难度：⭐⭐
   - 考点：VLAN 端口配置、FDB 查询

2. **MAC 地址飘移**
   - 现象：h1 和 h2 都能收发帧，但 FDB 表项频繁变化
   - 难度：⭐⭐⭐
   - 考点：FDB 学习逻辑、MAC 地址唯一性

3. **广播风暴**
   - 现象：注入一个广播帧后，事件数量爆炸式增长
   - 难度：⭐⭐⭐⭐
   - 考点：环路、STP、广播帧转发

4. **单向链路**
   - 现象：h1 能 ping 通 h2，但 h2 的回复到不了 h1
   - 难度：⭐⭐⭐⭐⭐
   - 考点：链路方向、FDB 学习、对端查询

### 使用流程

1. 选择场景：点击顶部的"场景 1/2/3/4"按钮
2. 观察现象：查看拓扑图、事件流、FDB 表
3. 分析问题：点击"显示提示"按钮，逐步获得线索
4. 验证答案：点击"显示答案"按钮，查看根因和修复建议

### 提示系统

- 每个场景有 4-5 条提示
- 按顺序揭示，从现象到根因
- 建议先自己分析，卡住后再看提示

## 常见问题

### Q: 页面打不开 / 显示空白？

A: 确保：
1. 使用 HTTP 服务器（不要直接双击 HTML）
2. 浏览器支持 ES6 模块（Chrome 61+、Firefox 60+、Safari 11+）
3. 检查浏览器控制台是否有错误

### Q: 如何清除练习题的进度？

A: 打开浏览器控制台（F12），执行：
```javascript
localStorage.removeItem('net-tutor-mistakes');
localStorage.removeItem('net-tutor-progress');
```
然后刷新页面。

### Q: 故障场景的事件数量为什么被限制？

A: 场景 3（广播风暴）会产生无限循环的帧，设置 `maxEvents=50` 防止浏览器卡死。真实环境中，广播风暴会耗尽交换机带宽和 CPU。

### Q: 如何添加自己的题目？

A: 编辑 `src/quiz/questions-stageX.js`，按以下格式添加：
```javascript
{
  id: 'stage1-q11',       // 唯一 ID
  stage: 1,                // 所属阶段
  type: 'single-choice',   // 题型
  question: '题目文本',
  options: ['选项A', '选项B', '选项C', '选项D'],
  answer: 0,               // 正确答案的索引（从 0 开始）
  explanation: '解析文本',
  lesson: { stage: 1, eventRange: [0, 10] }, // 可选：关联课程
}
```

### Q: 如何自定义故障场景？

A: 参考 `src/lessons/troubleshoot1.js` 的格式，创建新文件：
1. 定义 `spec`（拓扑和配置）
2. 定义 `injections`（注入的帧）
3. 添加 `hints`（提示）和 `solution`（答案）
4. 在 `troubleshoot.html` 中导入并添加按钮

## 技术细节

### 浏览器兼容性

- Chrome 61+
- Firefox 60+
- Safari 11+
- Edge 79+

需要支持：
- ES6 模块（`import`/`export`）
- `const`/`let`
- 箭头函数
- `Map`/`Set`
- `localStorage`

### 性能

- 单个场景的事件数量通常在 10-50 之间
- FDB 表项数量取决于网络规模（通常 < 100）
- 所有计算在浏览器端完成，无需服务器
- 大规模拓扑（> 10 台交换机）可能导致渲染变慢

### 无障碍

- 所有操作可用键盘完成
- 高亮一律双编码：颜色 + 描边/符号
- 灰度截图和色盲用户都能读
